Telegram-уведомления
Получить токен: в Telegram напишите @BotFather → команда /newbot → скопируйте выданный токен.
📱 Инструкция: Telegram-уведомления
1) Как получить токен бота
  1. В Telegram найдите @BotFather.
  2. Отправьте команду /newbot, задайте имя и username бота.
  3. Скопируйте выданный токен, вставьте в поле выше и нажмите «Проверить токен».
2) Как узнать свой chat_id
  1. Откройте в Telegram бота @userinfobot и нажмите «Старт».
  2. Бот пришлёт ваш chat_id (число) — пригодится, чтобы проверить отправку сообщений себе.
3) Как подключить клиента
  1. Введите токен бота и нажмите «Проверить токен».
  2. В карточке клиента нажмите «Сгенерировать ссылку».
  3. Нажмите «Скопировать текст для клиента».
  4. Отправьте текст клиенту в WhatsApp.
  5. Клиент нажимает на ссылку → «Старт» → готово.

Клиент сам подключается за 20 секунд. Вам не нужно объяснять, как найти chat_id — после нажатия «Проверить подключения» CRM сама привяжет его к карточке.

После подключения клиент будет получать:
  • 🔔 Напоминание о записи за 1 день
  • ✅ Уведомление о готовности авто
  • ⚠️ Приглашение на ТО
Токен хранится локально в этом браузере. Автоматические уведомления отправляются, пока CRM открыта.
Облачная база (Supabase)
Ключ хранится локально в этом браузере и используется для доступа к вашей базе. Данные кэшируются в IndexedDB — приложение работает и офлайн.
🗄️ Как подключить Supabase (бесплатно)
  1. Зарегистрируйтесь на supabase.com — это бесплатно.
  2. Создайте новый проект (New project), задайте пароль БД, дождитесь создания.
  3. Откройте Project Settings → API и скопируйте Project URL и ключ anon public.
  4. Вставьте их в поля выше (сохраняются автоматически).
  5. Один раз создайте таблицы: откройте SQL Editor → New query, вставьте код ниже и нажмите Run.
  6. Вернитесь сюда и нажмите «Принудительная синхронизация».
create table if not exists clients (
  id text primary key, name text, phone text, telegram_id text, notes text
);
create table if not exists cars (
  id text primary key, client_id text, brand text, model text,
  plate text, mileage int8, oil_interval int8, to_interval int8
);
create table if not exists bookings (
  id text primary key, client_id text, car_id text, services jsonb,
  total_price numeric, date date, time text, master text, status text
);
create table if not exists services (
  id text primary key, name text, price numeric, duration int8
);
create table if not exists expenses (
  id text primary key, category text, amount numeric, date date, comment text
);

-- доступ с anon-ключом (простой однопользовательский кабинет):
alter table clients  enable row level security;
alter table cars     enable row level security;
alter table bookings enable row level security;
alter table services enable row level security;
alter table expenses enable row level security;
create policy anon_clients  on clients  for all to anon using (true) with check (true);
create policy anon_cars     on cars     for all to anon using (true) with check (true);
create policy anon_bookings on bookings for all to anon using (true) with check (true);
create policy anon_services on services for all to anon using (true) with check (true);
create policy anon_expenses on expenses for all to anon using (true) with check (true);
anon-ключ виден в браузере — это нормально для личного кабинета. Для нескольких сотрудников позже включите Auth и более строгие политики RLS.

  • Кнопка «Экспорт в Excel» 📁 — выгрузка отчёта в файл .xlsx.
